# 多层膜构建指令

Filmstack Simulation 页「多层膜构建指令」文本框；右侧「膜系配置」切换预设时写入同语法字符串。自**入射侧 → 基底侧**书写；换行与多空格等价。

---

## 语法

| 构造 | 写法 | 要点 |
|------|------|------|
| 单层 | `材料 厚度_um [n k]` | 厚度 μm；`n k` 可选，须成对 |
| 非相干层 | `材料 厚度_um*` | 厚度后加 `*`：该层按非相干处理（与 `help_texts` / 解析器一致） |
| 周期 | `(子序列)^N` | N 为正整数；子序列内不可再含括号 |
| MG 掺杂 | `[q 掺杂物 基质 [n [k]]] 厚度_um` | q 为体积分数；`[...]` 后紧跟厚度 |

至少 2 层：入射半无限介质 + 基底半无限介质；常规写法首尾 `厚度=0`。

预设载入的也是 v1 **字面 μm 厚度**；修改「仿真波长范围」**不会**重算膜厚。

---

## 材料

1. **Simulation Database 工作区已有** → 只写名称，色散由 database 提供。
2. **未载入** → 须写 `材料 厚度 n k`（常数折射率）；`air` 内置 n=1, k=0。
3. **Maxwell-Garnett** → 掺杂物须在工作区；基质可写 DB 名，或 `[q inc host n [k]]` 固定基质 n/k。

---

## 边界层

解析后栈**首尾厚度恒为 0**（TMM 半无限边界）。

首尾层厚度 ≠ 0 时，解析器在同材料外侧自动补一层 `厚度 0`：

`air 0.1 … Si 0.1` → `air(0) | air(0.1) | … | Si(0.1) | Si(0)`

已写 `… 0` 则不重复补。首尾**不必是 air**（对称浸没：`BK7 0 1.5164 0 … BK7 0 1.5164 0`）。

---

## 示例

| 场景 | 指令 |
|------|------|
| 标准 AR | `air 0 (SiO2 0.1 Ta2O5 0.01)^5 air 0` |
| 含非相干层 | `air 0 SiO2 0.1* Ta2O5 0.05 air 0` |
| 全 inline n/k | `air 0 (SiO2 0.1 1.45 0 Ta2O5 0.01 2.1 0.001)^3 air 0` |
| DB + inline 混用 | `air 0 (SiO2 0.1 Ta2O5 0.01)^3 Si 0` |
| MG + inline 基质 | `air 0 1.0 0.0 [2e-6 au glass 1.5] 4000.0 air 0 1.0 0.0` |
| MG + DB 基质 | `air 0 [2e-6 au N-BK7] 1.0 air 0` |
| 对称浸没 | `BK7 0 1.5164 0.0 (H 0.01 1.5 0 L 0.02 1.3 0)^5 BK7 0 1.5164 0.0` |

---

## 约束

- 材料 token **不可含空格**（按空白分词；`[...]` 整体为一个 token）。
- `( … )^N` 内层不能含括号；可多次展开实现等效嵌套重复（如先展开 `(A B)^2` 再展开外层）。
- 层描述不完整（如 `SiO2 0.1 SiO2`）→ 解析失败。
- inline `n` 后下一 token 须为 `k`；否则该层按无 override 解析，可能报「材料不在工作区且未指定 n k」。
- MG：`[...]` 后**必须**紧跟厚度 token。
- 非相干：`厚度_um*` 仅作用于该层；优化路径的梯度对非相干层会退化（见 UI 帮助文案）。
