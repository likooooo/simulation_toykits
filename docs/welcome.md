# Simulation-toykits

基于 [MIT 协议](https://opensource.org/licenses/MIT) 的开源光学仿真工具集，以 Web 应用形式提供多层膜、光束与 PDE 等计算与可视化。

---

## 功能概览

- **Fresnel 计算器**：反射率 / 透射率、Fresnel 系数、膜系结构图、衍射角；支持 [refractiveindex.info](https://refractiveindex.info/) 材料库与自定义 n/k。
- **光束计算器**：Plane / Quadratic / Spherical 波，Flat-top、Hermite-Gaussian、Laguerre-Gaussian 等。  
Laguerre-Gaussian 仿真示例：[下载 MP4 视频](https://github.com/likooooo/simulation_toykits_assets/raw/main/ipynb/resources/laguerre_gaussain_beam.mp4)。
- **PDE 计算器**：Sturm-Liouville 及带时间项波动方程求解。

详细使用说明见应用内「Fresnel 计算器」页的 **📖 使用说明** 及 [docs/fresnel_calculator_usage.md](https://github.com/likooooo/simulation_toykits/blob/main/docs/fresnel_calculator_usage.md)。
